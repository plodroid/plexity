# Creative Direction

Create a premium SaaS-style showcase for the apps and websites in this project.

## Goal
- Make the products feel polished, intentional and genuinely usable.
- Use the real screenshots, recordings, logos and UI supplied in `assets/`.
- Keep the video understandable even with the sound off.
- Structure the animation so it can be recreated precisely in Remotion.

## Motion language
- Clean, restrained product motion inspired by high-end SaaS launch films.
- Prefer smooth ease-out movement and critically damped spring motion over bouncy presets.
- Use scale, position and opacity deliberately; avoid unnecessary movement.
- Keep spatial relationships consistent when an element enters, moves and exits.
- Use subtle depth and motion blur only where movement benefits from it.
- No generic glowing blobs, random gradients, floating glass cards or decorative animation spam.

## Visual hierarchy
Function → hierarchy → interaction → layout → typography → material → animation → decoration.

## Product rule
Never invent or approximate an app screen when a real asset can be supplied. If a required screen is missing, flag it as missing before the final Remotion build.
