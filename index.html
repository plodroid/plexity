What “verified” means

Plexity only marks a result verified when a public API confirms that username. Other platforms are shown as exact profile candidates because browsers cannot reliably inspect arbitrary sites across origins.

A username match does not prove multiple accounts belong to the same person. Plexity only uses public URLs and public API responses.
