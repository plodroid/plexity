# The Script

## Format

- **No voiceover**
- **No narration**
- The story is explained through motion, on-screen text, UI states, music and small interface sounds.
- Use only subtle UI SFX: clicks, blips, pops, whooshes, upload sounds, soft error ticks and confirmation chimes.
- Keep text short. The motion graphics should do most of the explaining.

## SCENE 1 - HOOK (0:00-0:07)

- **Visual:** dark screen with one glowing video thumbnail centered. It multiplies into four copies.
- **On-screen:** "You made one video." → "Now post it four times."
- **SFX:** soft bloom, then three small duplication blips as the thumbnail multiplies.
- **Motion:** keep the opening simple, centered and dramatic.

## SCENE 2 - THE PROBLEM (0:07-0:22)

### Beat 1
- **Visual:** four upload tabs stack up quickly: TikTok, Instagram, YouTube and Facebook. Each has its own upload window.
- **On-screen:** "Open every app."
- **SFX:** rapid tab clicks and soft UI whooshes.

### Beat 2
- **Visual:** a cursor copies a title, switches tabs, pastes it, then repeats the process for hashtags.
- **On-screen:** "Copy. Paste. Repeat."
- **SFX:** copy click, paste click and quick tab-switch ticks.

### Beat 3
- **Visual:** loading spinners, one failed upload, mismatched captions and a ticking clock. The scene becomes desaturated and cluttered.
- **On-screen:** "Slow." → "Inconsistent."
- **SFX:** subtle spinner hum, one error tick and quiet clock ticks.
- **Motion:** make this section feel intentionally repetitive and annoying.

## SCENE 3 - THE REVEAL (0:22-0:30)

- **Visual:** the clutter blurs away. A single violet point of light expands into the Argon logo with a soft bloom.
- **On-screen:** **Argon** / "Post once. Everywhere."
- **SFX:** rising tone, soft bloom and one clean logo chime.
- **Motion:** this is the visual reset. Calm, premium and spacious.

## SCENE 4 - DROP IT ONCE (0:30-0:42)

- **Visual:** the Argon window floats in a slightly tilted frame. A video file is dragged into the drop zone. The thumbnail glows and snaps into place with a soft ripple.
- **On-screen:** "Drop it once." / "One video. That's it."
- **UI text:** "Drop video here"
- **SFX:** drag whoosh, soft drop pop and ripple blip.
- **Motion:** make the interaction feel effortless.

## SCENE 5 - WRITE IT ONCE (0:42-0:55)

- **Visual:** match-cut to the title, description and hashtag fields. The information is entered once. Four platform chips activate one by one as the content flows into them.
- **On-screen:** "Write it once." / "One title. One description."
- **UI text:** "Title" / "Description" / "Hashtags"
- **SFX:** soft typing ticks, chip activation blips and a clean flow sound.
- **Motion:** shift the background hue slightly to mark a new chapter.

## SCENE 6 - ONE CLICK (0:55-1:10)

- **Visual:** the cursor hovers the gradient **Spread** button and clicks. A beam splits into four streams that travel to the four platform icons. Each one lands with a checkmark.
- **On-screen:** "One click." / "Live everywhere."
- **UI text:** **Spread**
- **SFX:** hover shimmer, button click, four short travel whooshes and four light success chimes.
- **Hero moment:** make this the most polished shot in the whole video.

## SCENE 7 - 4 → 1 (1:10-1:22)

- **Visual:** split screen. The left side shows the old way: four tabs, desaturated and cluttered. The right side shows Argon: one clean window with vivid colour. Three large lines animate in one by one.
- **On-screen:** "4 apps → 1" / "4 uploads → 1" / "4 captions → 1"
- **SFX:** cluttered UI ticks on the left, clean confirmation blips on the right, and one subtle impact for each comparison line.
- **Motion:** make the contrast instantly understandable without explanation.

## SCENE 8 - CLOSE (1:22-1:32)

- **Visual:** the UI fades into a full-screen gradient bloom. The Argon logo sits centered with the tagline below. Hold the final frame for 2 seconds.
- **On-screen:** **Argon** / "Post once. Everywhere."
- **Optional small line:** "A concept by plodroid."
- **SFX:** one soft closing chime as the music resolves and fades out.

# Production Notes

- **No voiceover or narration.**
- Build the Argon interface as HTML/React or a Figma reference, then animate the actual UI directly in Remotion.
- Use real Argon branding and supplied assets whenever available.
- Use clean platform glyphs instead of large busy platform logos.
- Keep text short and readable. Never explain something with text if the animation already makes it obvious.
- Sound design should stay subtle: clicks, blips, pops, small whooshes, upload sounds, error ticks and light chimes.
- Leave breathing room between text beats so the viewer can understand the interface.
- For a 60-second version, shorten Scene 2 and remove Scene 7.
- For a 9:16 version, enlarge typography and re-frame the UI shots vertically.

## Core Message

**Drop it once.**  
**Write it once.**  
**Spread everywhere.**
