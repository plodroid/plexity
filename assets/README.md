# Assets

Put every real visual or audio source for the Remotion video somewhere inside this directory.

- `screenshots/` — PNG, JPG or WebP product screenshots.
- `video/` — MP4/WebM screen recordings and product clips.
- `logos/` — SVG/PNG logos and icons.
- `audio/` — WAV/MP3 voiceover, music and sound effects.

After adding a file, add it to `manifest.json` so the website can display it and the eventual Remotion build can map scenes to exact filenames.

Prefer names such as `scene-01-dashboard.png` instead of `Screenshot (42).png`.
